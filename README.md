# WP4 FIMI attribution dataset

This repository holds the Work Package 4 dataset of the DE-CONSPIRATOR project (Horizon Europe, Grant Agreement No. 101132671), together with its codebook and documentation.

The dataset records public attributions of foreign information manipulation and interference (FIMI) made by European institutions. Each record is one incident that an institution attributed in a published document. We do not classify content ourselves: the dataset reports what institutions attributed, to whom, and when.

Deliverable D4.2 describes the dataset and its method. We will add the data files, the codebook and the release history here when D4.2 is submitted.
